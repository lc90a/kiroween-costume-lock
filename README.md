# Costume Lock Studio · 换装锁衣

Kiroween 2026 · Category: Costume Contest

## 真实问题

2026-11-20，一条用一张紫色半透明古风纱裙（金色刺绣、水晶流苏头饰）的照片生成 10 秒跳舞视频，结果衣服被换掉了——她只回了一句：“衣服完全不一样了。”

这不是个例：AI 图生视频每次都是一次新的随机采样，服装、颜色、头饰、脸都可能漂移。Costume Lock Studio 做的就是一件事：**在生成之前，把衣服锁死**。先出定妆图、抽帧验衣，确认衣服没跑偏，再转跳舞视频。

## 演示流程（4 步）

1. **选人像**：上传自己的照片，或直接用内置的紫色纱裙定妆图。
2. **选服装**：紫色半透明古风纱裙 · 金色刺绣 · 水晶流苏头饰（已验证的紫色锁定版）、淡青色轻纱长裙 · 银饰流苏、白色短裙 · 河边夕阳。
3. **拿提示词**：自动生成两条锁死提示词——生图提示词（服装颜色锁定 + 黑长发 / 流苏 / 轻纱 / 魏晋服饰 / 莫兰迪配色，颜色按服装固定）和 10 秒跳舞视频提示词（一镜到底、固定机位、服装 / 脸 / 发型全程锁定，不许换衣、不许换色），一键复制。
4. **验帧再转视频**：按清单逐项打勾（裙色、刺绣、头饰、脸、背景），全部通过再去生成视频。

## 诚实说明（范围）

- v1 是一个**提示词锁衣工作室**：生成锁死的提示词、做验帧清单。图片和视频的生成发生在用户自己的生成器里，本仓库不调用任何生成 API，仓库里没有任何 API Key。
- 生成仍是一次新的随机采样：锁死提示词能大幅降低衣服漂移，但不能保证 100%。验帧清单就是为此准备的。
