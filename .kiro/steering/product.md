# Product Steering — Costume Lock Studio （换装锁衣）

## 产品愿景

AI 跳舞视频最常见的失败不是舞跳得不好，是衣服被换了。Costume Lock Studio 让用户在生成之前就把衣服锁死：先定妆、再验衣、最后才转视频。

## 锁衣规则（不可违反）

1. **颜色必须写死**：每套服装都有固定的颜色描述，提示词里不许只写“莫兰迪配色”这种不定颜色——不定的颜色出图就是随机的。
2. **服装四件套必须写全**：裙色 / 面料、刺绣、头饰、发型，四项缺一不可。
3. **脸和背景也要锁**：只锁衣服不够，脸和背景也会漂移，提示词里要同时锁定人物、发型、背景。
4. **先图后视频**：先出定妆图，抽帧验衣通过后，才转 10 秒跳舞视频。不许跳过验衣直接生成视频。
5. **诚实声明**：每次生成都是一次新的随机采样，锁死提示词只能降低漂移率，不能保证 100%。不要向用户承诺“绝对不变”。

## 目标用户

- 用 AI 做古风 / 舞蹈视频的创作者
- 被“衣服完全不一样了”打回过的人

## 不做的事情（v1）

- 不调用任何图片 / 视频生成 API，不存 API Key
- 不做账号、登录、云端存储
- 不替用户生成视频，只给锁死的提示词和验帧清单
