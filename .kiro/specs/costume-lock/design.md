# Design — Costume Lock Studio

## 架构

纯静态单页应用，无框架、无构建、无后端：

```
app/
  index.html          # 结构：4 个步骤区块
  app.js              # 服装数据 + 提示词生成 + 复制 + 验帧状态
  styles.css          # 样式
  assets/
    demo-purple-still.webp   # 内置紫色纱裙定妆图（已验证）
```

## 数据模型

每套服装一个对象：

```js
{
  id: "purple",
  name: "紫色半透明古风纱裙",
  colorLock: "紫色半透明古风轻纱长裙，金色刺绣，水晶流苏头饰",
  morandi: "紫色莫兰迪配色（紫罗兰、淡紫、银白为主）",
  dress: "紫色半透明古风轻纱长裙，金色刺绣",
  headdress: "水晶流苏头饰",
  background: "樱花庭院背景"
}
```

三套服装：

| id | 服装 | 颜色锁定 |
|----|------|---------|
| purple | 紫色半透明古风纱裙 · 金色刺绣 · 水晶流苏头饰 | 紫色莫兰迪（紫罗兰、淡紫、银白） |
| cyan | 淡青色轻纱长裙 · 银饰流苏 | 青绿莫兰迪（淡青、银白、浅灰） |
| white | 白色短裙 · 河边夕阳 | 暖白 / 夕阳金（白色、暖金） |

## 提示词生成

- 生图提示词 = 颜色锁定句 + 用户原提示词句式（黑长发、流苏、轻纱、魏晋服饰、莫兰迪配色），其中“莫兰迪配色”替换为该服装的固定配色。
- 视频提示词 = 参考图锁定句 + 服装四件套 + 10 秒一镜到底、固定机位、舞姿连贯、不跳跃、不换舞 + 不要字幕/旁白/logo/水印。

## 交互

1. 上传图片 → FileReader 本地预览；“用内置定妆图” → 显示 `assets/demo-purple-still.webp`。
2. 点服装卡片 → 切换选中态，两条提示词重新生成。
3. 点“复制” → `navigator.clipboard.writeText`，失败时回退到 `textarea + execCommand`，按钮文案变“已复制”。
4. 验帧清单 checkbox → 计数并更新提示文案，5 项全勾显示通过状态。

## 样式

中文界面，暖色纸感背景，紫色为主色（呼应紫色纱裙），步骤卡片纵向排列，移动端可用。
